# Особистий бюджет у Telegram

Підготовлена перша версія для таблиці `budget_october_2026_clean`.
Бот ще не підключений і не розгорнутий. Тестові записи в реальну таблицю не вносилися.

## Як користуватися

- `/start` відкриває меню й увімкне нагадування.
- «Витрата»: сума → категорія → рахунок → опис → підтвердити.
- «Надходження»: фактична сума → рахунок → опис → підтвердити.
- «Переказ»: сума → звідки → куди → опис → підтвердити; не є витратою.
- «Витрата за вчора» записує вчорашню дату. Під час внесення можна змінити її командою `/date 2026-10-01`.
- «Залишки» або `/status` читає підсумки таблиці. Борг 7 000 грн залишається інформаційним.
- `/cancel` скасовує чернетку. `/stop` вимикає нагадування.
- Щодня 23:00: внести витрати за день. 09:01: перевірити вчорашні витрати.
  Час Europe/Kyiv, автоматично враховує перехід на зимовий/літній час.
  Короткий збій до двох годин допускає пізніше нагадування; старі пропущені не розсилаються пачкою.

## Підключення без другого Render-сервісу

1. Створи окремого бота через `@BotFather`. Токен введи тільки в Render Environment як `BUDGET_BOT_TOKEN`.
   Поточний `BOT_TOKEN` відключень залиш незмінним.
2. Вкажи свій числовий Telegram ID у `BUDGET_OWNER_ID`. Він може збігатися з `ADMIN_ID` бота відключень.
3. У Google Cloud створи сервісний обліковий запис і ввімкни Google Sheets API.
   Надай email цього облікового запису права редактора тільки жовтневої таблиці.
   JSON-ключ введи в Render Environment як `GOOGLE_SERVICE_ACCOUNT_JSON`.
   Ніколи не додавай токен чи JSON-ключ до GitHub або чату.
4. Додай папку `budget_bot/` у репозиторій поряд із наявним `bot.py`.
   Старий `bot.py` не потрібно замінювати.
5. Залиши поточні залежності й додай у Build Command установлення нових:
   `pip install -r requirements.txt -r budget_bot/requirements-budget.txt`.
   Якщо поточний файл залежностей має іншу назву/шлях, збережи саме його.
6. Установи змінні з `.env.example`. `LIGHT_BOT_PATH=bot.py` — шлях до поточного бота.
   `BUDGET_SPREADSHEET_ID=1hC5r_LVj6exGy5rgQWO3c_ntGLHU--hr5WaLrowOHLw`.
7. Потрібен наявний постійний диск: каталог `BUDGET_DATA_DIR=/var/data/budget` має бути на ньому.
   Чернетки, черга й захист від повторень зберігаються в окремій SQLite-базі; база відключень не змінюється.
   Якщо диска немає, спершу узгодити збереження даних і вартість — не запускати на тимчасовому каталозі.
8. Start Command: `python budget_bot/run_bots.py`. Один сервіс, один екземпляр.
   Він запускає два незалежні процеси з різними токенами й перезапускає процес після аварійного завершення.
   Якщо це Web Service, за наявності `PORT` він надає просту перевірку стану HTTP;
   для Background Worker порт не потрібний.
9. Напиши новому боту `/start`. Внеси реальну невелику витрату й перевір її в журналі.
   Перевір статус, переказ і нагадування, потім перевір RAM/CPU у Render та роботу бота відключень.

**Додатковий сервіс не створюється**, але достатність пам'яті на поточному тарифі ще не перевірена.
Render рекомендує окремі сервіси для ізоляції програм; спільний запуск тут — обраний компроміс для економії.
Перед зміною Start Command запиши поточний — його можна повернути для відкату.
Розгортання на Render і зміни GitHub у цьому пакеті ще не виконані.

## Межі та надійність

- Доступ тільки для дозволеного Telegram ID у приватному чаті; групи й інші користувачі не мають доступу.
- Запис тільки в `Журнал!A5:G308`, бо поточні формули підсумовують саме ці рядки.
  На межі бот зупиниться, а не записуватиме витрати, які підсумки не бачать.
- Значення записуються як числа/текст через атомарний Sheets batchUpdate;
  формули, форматування, валідації, інші вкладки та ліміти не перезаписуються.
- Повторне підтвердження, перезапуск і втрата відповіді Google перевіряються за маркером у примітці опису.
  Не видаляй ці службові примітки з незавершених записів. Підтверджена черга відновлюється після перезапуску.
- Якщо Google недоступний, бот каже «в черзі», а не «внесено». Зайнятий рядок не перезаписує.
- Google Sheets не підтримує умовний запис «лише якщо порожньо». Не редагуй одночасно з підтвердженням
  той самий наступний порожній рядок вручну; між перевіркою й записом залишається коротке вікно конкуренції.
- Telegram не гарантує рівно одне надсилання після втрати мережевої відповіді: в рідкісному такому випадку
  нагадування може прийти повторно. Самі витрати мають окремий захист від дублювання.
- Працює з одним місяцем. На листопад створи нову бюджетну таблицю та онови ID, вкладку, рік і місяць.
  Незавершені записи жовтня спершу потрібно внести; бот не переносить їх у листопад автоматично.
- Голосові, фото чеків і довільне розпізнавання тексту до першої версії не входять.
